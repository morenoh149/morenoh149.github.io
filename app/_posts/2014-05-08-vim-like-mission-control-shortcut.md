title: Vim-like mission control shortcut
---

So I use iterm2 on my mac. And there's a shortcut option-spacebar which switches back and forth between a desktop and iterm2 in fullscreen.
I do most of my work that way, switching between a browser and code. Recently however I've been following some
screencasts on youtube which required me to switch between broswer, fullscreen iterm2 and fullscreen youtube player.
This was the perfect time to change the mission control shortcut on my mac.
<img src="https://dl.dropboxusercontent.com/s/6pxosnnirl0f6ww/Screenshot%202014-05-08%2016.43.29.png"/>

As you can see I mapped moving one screen left or right to `⌥h` and `⌥l` so I can switch using vim-like keys.
