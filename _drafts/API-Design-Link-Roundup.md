horrible API design decisions. So I started looking up materials so I know
what makes a good API.

* [Matt Gemmell on API Design](http://mattgemmell.com/api-design/)
* [Best Practices for Designing a Pragmatic RESTful API](http://www.vinaysahni.com/best-practices-for-a-pragmatic-restful-api)
* [HTTP API Design By Heroku](https://github.com/interagent/http-api-design)
* [Consumer-Centric API Design](https://github.com/tlhunter/consumer-centric-api-design)
