# Intro to irc with weechat

say you're a dev. One of the best ways to improve your skill is to actively participate on irc.
You're terminal should be open all the time anyway. You can get help way more interactively than
on stackoverflow. The problem is getting help in the first place.

1) how to setup freenode
  * autoconnect
  * auth with sasl
  * autojoin channels
2) how to message directly
3) keep the windows open all the time, go over setup for noticing when someone replies directly to you
4) the wonderful world of other networks, efnet, rizon, dalnet, other interests

I live in my terminal. I think irc is a great way for every developer to learn and really engage with
fellow programmers. My skills have only increased since spending more time on irc. And quite frankly
it's a different kind of entertainment than facebook or twitter can offer.

to limit activity to messages set
/set weechat.look.buffer_notify_default

to view new activity
esc + a
