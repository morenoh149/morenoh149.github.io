title: Top 5 brew tools you should install on OSX
---

* jq - Like sed for json data `brew install jq`
https://stedolan.github.io/jq/tutorial/
* Ag - A fast deep searching tool. Useful for finding files that contain some
word `brew install the_silver_searcher`
* bro - Crowdsourced man pages `brew install bro`
* curl - Useful for testing apis `brew install curl`
* wget - Useful for quickly downloading files from the internet `brew install
wget`
* gist - Useful for quickly sharing code snippets with people on irc `brew
install gist`


Bonus:
* cowsay - Useful for display funny messages `brew install cowsay`

* cloc - Count, and compute differences of, lines of source code and comments.
