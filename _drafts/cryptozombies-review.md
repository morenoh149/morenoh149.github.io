## Lesson 1
Walks you through the creation of a simple contract written in solidity piece
by piece. First impressions of the language are it uses javascript-esque
syntax but you all variables are statically typed. You must declare the type
when using numbers or strings. The function signatures feel very java-esque
with the explicit declaration of public/private functions. Functions in soldity
are public by default, so you should make reserved functions explicitly private.
The last chapter in this lesson demos web3.js and how it would call a smart
contract.
