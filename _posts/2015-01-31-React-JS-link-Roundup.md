Here's a small collection of links for developers looking to learn react.js.

* The official Facebook [React docs](http://facebook.github.io/react/docs/getting-started.html)
* Do the official [Tutorial](http://facebook.github.io/react/docs/tutorial.html)
* Read [Thinking in React](http://facebook.github.io/react/docs/thinking-in-react.html)
* The [Component Lifecycle](http://facebook.github.io/react/docs/component-specs.html)
describes the core events that happen in a react component. **important**
* This [Terminology](http://facebook.github.io/react/docs/glossary.html) page
really helped me understand the difference between a react element and react
node.
* When you start writing more complex jsx this [if-else page](http://facebook.github.io/react/tips/if-else-in-JSX.html)
is useful.
* The difference between [props vs state](https://github.com/uberVU/react-guide/blob/master/props-vs-state.md)
* [A thrown to the wolves intro to react](http://tech.pro/blog/2020/a-thrown-to-the-wolves-hands-on-introduction-to-react)
contains some errata due to the changes in react's api since this tutorial was
written. But it's what I used personally to learn react.

If you have any other links that were useful to you for learning react.js
chime in the comments.
